Rules
-----
- wilson_system owns VibState, MolecularProperty and MolPropsCollection; wilson_main is to import them (D4).
- No import cycles: system_data.py imports nothing from wilson_intensities. In refac_rsp_eval, evaluate.py,
  features.py and pipeline.py import system_data; plan.py does not.
- One MolSystemData = one origin: one DataOriginInfo, i.e. one file or calculation. MolSystemData.load(origin, names)
  reads everything from that origin in one reader call.
- The anharmonic state calculation belongs here: VPT2 gives state energies, the data MolSystemData holds. vpt2.py
  moves too, so that wilson_system does not import wilson_intensities.
