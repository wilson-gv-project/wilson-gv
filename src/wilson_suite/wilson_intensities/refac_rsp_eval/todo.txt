Decisions and known limits
--------------------------
- B7 (2026-10-09): each term's motif has exactly one resonance point: number of conditions = number of axes
  = rank of the condition matrix. Checked when compiling (CompiledTerm.from_VibPertTerm, plan.py).
  Not supported: fewer conditions than axes (a line, E8), more conditions than axes. Malformed: conditions that
  contradict each other. A term without conditions passes: no spectrum, but its other parts can be computed.
- Denominators (2026-10-10): w is always the Hessian eigenvalue (nc_sqrt_eigval); an energy difference always
  uses the chosen states. derive's is_pert_wf_diff tells them apart (True: energy difference); to_str prints
  both alike, e.g. <['a'],[]>.
- states_choice must follow the vib analysis regime: GVPT2, VPT2 -> anharmonic; harmonic -> harmonic. The two
  differ in 272 of 340 formaldehyde coefficients. from_datadict cannot know the regime, so it has no default
  (2026-10-11): the caller passes the choice.
- No feature is dropped for its amplitude (2026-10-09), as in the old code. Weak features stay, and so do
  features whose rows cancel (a record: FeatureResult.cancelling(rel_tol) lists them). A term with coefficient 0
  never becomes a row (FeatureResult.zero).
- Drawing by domains cuts each feature at its box (draw_window docstring). Formaldehyde, dynrange 100: 1.05 % of
  the max intensity. A weak peak next to a strong one in another domain can be 12-36 % off. The old code cuts
  the same way (C3).

        class since B1.) Keep the imports free of cycles: plan.py and system_data.py import each other only for

[ ] D5  Data-dict contract: what the evaluator assumes about the data dict. Old and new assume the same, so
        C2, C3 and G1 cannot catch a mismatch. Write it down (E4); check the cheap parts when loading (H5).
        - [ ] names: properties under prop_trivname names (dipgrad, polgrad, polhess, diphess, cff, ...);
              frequencies under 'nc_sqrt_eigval'; states under 'harmonic_states' and 'anharmonic_states'.
        - [ ] index order: mode indices first, in the order of the term's labels, then Cartesian (x, y, z = 0, 1, 2),
              e.g. polhess[a, b, x, y] (_make_func_to_compute_avrg).
        - [ ] full tensors: every order of mode indices is filled, e.g. cff[a, c, c] is read as written, not sorted.
              A reader that filled one triangle only would give zeros.
        - [ ] modes: 0 .. n-1, n = len(nc_sqrt_eigval); every array has n entries per mode axis, in that order.
        - [ ] units: properties in au, used as they are; nc_sqrt_eigval and state energies in cm-1, converted to Eh.
              Coefficients come out in au.
        - [ ] coordinates: a derivative such as dipgrad depends on how the vibration coordinate is measured, e.g.
              mass-weighted or dimensionless (the two differ by a factor sqrt(w)). Open: which one the data dict
              uses, and whether derive's 1/w factors assume the same. A mismatch puts every coefficient off by
              powers of sqrt(w), and C2, C3 and G1 cannot notice (old and new read the same dict).
        - [ ] state energies: relative to the ground state (0, no zero-point energy); keys are tuples of mode
              labels, e.g. ('0', '0') = 2 quanta in mode 0; every fundamental is in 'harmonic_states'
              (from_datadict takes the mode labels from there, also for anharmonic states).
        - [ ] zero threshold: |value| < 1e-18 counts as 0 (zero_tol in eval_avrg_per_indexdict,
              eval_non_avrg_per_indexdict). A fixed number, so it assumes au and these sizes: rounding noise about
              1e-19, real averaged values 1e-9 or more (formaldehyde).

    e.g. draw_window came with a test that measures how far it is from draw_all.

    orchestrator next to WilsonSimulation. Delete code instead of commenting it out.

H4  Don't store a value that can be derived from other fields; frozen dataclasses where possible.
    Not frozen yet: Box, SpectralFeature, SpectralWindow, RectangularDomain, PrecalculatedData.
H5  Validate when an object is built; check types only at entry points.
H6  plan.py runs, and its output can be checked, without molecular data (test_plan.py).
