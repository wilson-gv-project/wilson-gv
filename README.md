# wilson-suite

1. Get required repos with `setup.sh`:
   - wilson_main
   - wilson_utils
   - wilson_derive
   - wilson_experiment
   - wilson_intensities
   - wilson_analysis
   - CQCParse
2. `pip install -r requirements.txt` - install obtained packages.
3. Add to path python module `wilson_suite.py`. Aliases are defined there, so `import wilson_suite.main` is possible
